# Warrior Action Icon Prompts

Shared constraints for every icon:

- Square game action icon.
- Same size and framing across set.
- Painted high-fantasy MMO hotbar icon style, inspired by ornate FFXIV-style skill icons but not copying any existing icon.
- Full illustrated background, no transparency.
- Dark bronze / iron frame feel, strong silhouette, readable at small mobile size.
- Dramatic lighting, high contrast, crisp edges, no text, no letters, no watermark.
- Icon content must show action effect clearly.

## Strike

Create a square warrior action icon for "Strike". Show a heavy one-handed axe or sword cutting diagonally through the frame, bright orange impact sparks at the blade edge, dark battlefield background, bronze rim glow. The icon should read as a basic physical attack. No character face, no text.

## Provoke

Create a square warrior action icon for "Provoke". Show a horned warrior helm silhouette shouting forward with red threat rings and a taunting flare pulling enemy attention, dark smoky background, sharp crimson highlights. The icon should read as redirecting enemy targeting to the tank. No text.

## Cover

Create a square warrior action icon for "Cover". Show a broad shield interposed in front of a smaller ally silhouette, golden barrier arc catching an incoming red slash, dark blue battlefield background. The icon should read as protecting a targeted ally from a single hit. No text.

## Wall

Create a square warrior action icon for "Wall". Show a massive stone-and-iron shield wall rising across the foreground, four faint ally silhouettes protected behind it, warm gold defensive aura, dark battle smoke background. The icon should read as party-wide damage reduction. No text.

## Vengeance

Create a square warrior action icon for "Vengeance". Show a warrior shield cracked with glowing red retaliation energy, an incoming blade reflected backward as crimson sparks, black iron background. The icon should read as countering the next direct hit. No text.

## Shield Bash

Create a square warrior action icon for "Shield Bash". Show a heavy round shield smashing into a casting sigil, blue-white magic circle shattering into fragments, impact burst from left to right. The icon should read as interrupting a cast with small damage. No text.

## Steel Cyclone

Create a square warrior action icon for "Steel Cyclone". Show a warrior axe spinning in a circular iron storm, silver arcs and orange sparks spiraling around a dark center, heavy delayed burst feeling. The icon should read as a powerful spinning tank attack. No text.

## Rampart

Create a square warrior action icon for "Rampart". Show a lone armored tank bracing behind a tower shield, layered golden-blue defensive wards stacking in front, sturdy stone background. The icon should read as self damage reduction before enemy action. No text.
