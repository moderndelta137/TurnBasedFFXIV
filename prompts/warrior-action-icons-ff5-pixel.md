# Warrior Action Icon Prompts - FF5 Pixel Style

Shared direction:

- Alternate Warrior action icon set.
- Square `76x76` final assets.
- Inspired by classic Final Fantasy V-era pixel art UI: low-resolution pixel shapes, flat shading, limited palette, chunky silhouettes.
- No modern painterly rendering.
- No gradients except tiny controlled pixel ramps.
- No text, no letters, no watermark.
- Black or very dark fantasy UI frame.
- Background must be filled, not transparent.
- Icons must read clearly at mobile hotbar size.
