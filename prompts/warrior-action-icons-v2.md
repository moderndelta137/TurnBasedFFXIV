# Warrior Action Icon Prompts V2

Reference direction:

- Match provided FFXIV hotbar icon readability: tiny `76x76` square icons.
- Simple central symbol over painted gradient background.
- Thick dark beveled frame.
- Saturated color, compact silhouette, airbrushed fantasy effect.
- Less modern AI concept art. Less realism. Less scene detail.
- No transparent background.
- No text, no letters, no watermark.
- Final workspace files should be resized to `76x76`.
