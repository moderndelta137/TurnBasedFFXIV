Ownership rule:

- Overview doc owns product goal, scope, risks, and success criteria.
- Game flow doc owns lobby/run/reward loop.
- Combat doc owns turn rules, intent, targeting, timing, enemy/boss behavior.
- Grid doc owns movement, cells, facing, warnings, and positioning questions.
- Jobs/loadout doc owns jobs, actions, gear, passives, autosave, and progression.
- UI/UX doc owns screen/panel/interaction rules.
- Visual/audio doc owns art and presentation direction.
- Data model doc owns design-facing object shapes.
- Enemy pattern idea pool stores non-final mechanic ideas for future encounter design.

Avoid duplicate truth. Link to owning doc instead.
